# Project Instructions

- Use TypeScript strict mode.
- Follow the existing Expo Router project conventions.
- Keep screens presentational and thin.
- Screens must not import AsyncStorage or call fetch directly.
- Business logic belongs in feature services.
- Data access belongs behind repository interfaces.
- Keep mock and REST implementations interchangeable.
- Use dependency injection through the composition root.
- Validate external API responses and stored JSON.
- Do not store passwords or sensitive tokens in AsyncStorage.
- Add or update tests for each behaviour change.
- Run lint, tests and TypeScript checks after implementation.
- Never claim a check passed unless it was executed.
- Do not commit, push, or perform destructive Git operations without authorization.
